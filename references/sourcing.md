# 没有实习 / 经历普通怎么办

配合 `SKILL.md` 的「路径 A：从 0 到 1」使用。

## 先纠正一个判断

**应届生没有正式实习很正常。公司招新人，也不会真要求你一入职就能独立解决问题。**

真正被扣分的是**看起来完全没准备**——简历上只有课程名称和社团头衔，看不出你理解这个岗位要做什么。

区别就在这一句：

- ❌ 「我还没实习，所以没什么可写」
- ✅ 「我想做运营，所以我做了这些准备」

## 素材来源清单

没有实习，不等于没有素材。按可用度排序：

| 来源 | 怎么用 |
|---|---|
| **课程项目 / 大作业** | 只要真做过就算，写清楚你负责什么、产出什么 |
| **毕业论文 / 课程论文** | 有研究过程的算，写研究问题、方法、结论 |
| **社团 / 学生会 / 志愿活动** | 写具体分工和规模，**不写头衔** |
| **兼职 / 家教 / 校园代理** | 写客户量、处理过什么问题、结果 |
| **竞赛** | 写题目、你的角色、方法、结果 |
| **个人练习 / 求职准备项目** | 见下节——**这是最被低估的一类** |

**关于社团**：招聘方不关心你参加过多少活动，关心这些活动证明了你具备什么能力。"外联部部长"是头衔，"带 8 人团队拉赞助，谈成 3 家共 1.2 万"才是能力。

## 主动补项目：针对性最强的做法

如果目标岗位要的能力你完全没有证据，**花 3-7 天做一个**。

**不是刷课、不是考证**，是产出一个能给别人看的东西：

| 目标岗位 | 可以做的练习 |
|---|---|
| 内容运营 | 拆解 10 个同类账号，按选题 / 标题 / 发布时间 / 互动数据建分析表；出一周内容规划；写 3 篇模拟文案 |
| 电商 / 商品运营 | 选一个商品详情页做分析，输出优化建议 |
| 数据分析 | 找一份公开数据集，做完整分析：清洗 → 定义指标 → 结论 → 可视化 |
| 产品经理 | 拆解 10 个同类产品做功能矩阵对比；挑一个缺失功能写 PRD |
| 市场 / 竞品 | 选一个赛道，做竞品对比表 + 市场规模测算 |
| 技术 / 开发 | 做一个小工具或开源项目，哪怕只有几百行 |

**关键是产出物**：一张对比表、一份分析报告、一个能跑的工具。**有产出物，才有东西可写。**

这个过程本身就是筛选——如果连三天的练习都不愿意做，那可能不是真的想做这个方向。

## 怎么把它写进简历

**不要写"我学习了 XX"**，要写**动作 + 产出**。

| 空话写法 | 具体写法 |
|---|---|
| 学习了内容运营 | 为准备内容运营岗位，拆解 10 个同类账号，从选题、标题、发布时间、互动数据四个维度建立分析表，并整理一周内容规划 |
| 自学了数据分析 | 用某公开数据集完成完整分析：清洗 1.2 万条记录，定义 4 个核心指标，输出结论与可视化图表 |
| 对产品经理很感兴趣 | 拆解 10 个同类产品的功能矩阵，针对缺失的「批量导出」功能撰写了一份 PRD |

**读起来像"我做过"，而不是"我想做"。**

## 边界：什么算诚实，什么算伪造

- ✅ 如实写成「为准备 XX 岗位做的练习」——**主动标注来源，没人会觉得这该是商业项目**，反而说明你认真
- ✅ 课程项目按真实规模写
- ✅ 竞赛、论文按实际角色写
- ❌ 把练习包装成"实习经历"
- ❌ 编造公司、职位、任职时间
- ❌ 把课程作业说成商业项目

**口碑成本远大于收益。** 招聘方一个电话就能核实实习经历，而编造的代价是进黑名单。但主动做的练习**不需要隐藏**——它证明的正是招聘方最想看的：你会不会自己找问题、动手解决。

## 一句话

**新人没有经验不扣分，完全没有准备才容易被跳过。**

如果用户说"我什么都没有"，不要接受这个前提——先按上面的清单逐项问一遍，几乎总能挖出东西；挖不出来，就帮他设计一个 3-7 天能完成的练习。
